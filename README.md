# Полка

Офлайн-коллекция под один плеер и одни наушники: Cayin N3Ultra и Moondrop Blessing.
Хард-боп Blue Note, необычная электроника, ню-джаз и Tom Waits.

Без стриминга и без алгоритма. Альбом попадает на карту, потому что его выбрали.

## Правила полки

- **FLAC 24/96–24/192 или DSD.** CD-качества хватает, когда мастер не лучше: электронику 90-х сводили под 16/44.1.
- Файл 96 кГц, сделанный из записи на 44.1, — не хайрез. Цифра в названии звук не добавляет.
- MQA не беру. SACD-образы тоже: плеер на них падает.
- Ссылки — только на легальные магазины.

## Что дальше

★ — с этого начать: формат подтверждён на странице магазина.
Прочерк в «Формате» — смотри страницу перед покупкой: хайрез одного альбома в разных странах разный.
Блюза здесь нет. Эмбиент — только исключения.
